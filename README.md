# NTD Rail Analytical Framework

Operator efficiency, safety, and productivity analysis for U.S. urban rail, 2015–2024.

**👉 [Launch the framework](https://ajacomem.github.io/ntd-rail-analysis/)**

## What's here

- **Walkthrough** — 12-stop guided tour through all artifacts
- **Eight artifacts** — efficiency frontier, productivity decomposition, cost structure,
  head-to-head comparison, national map, safety vs efficiency, worker assault rates,
  system expansion effects

## Techniques

Data Envelopment Analysis (BCC) · Malmquist productivity index · cost structure
small-multiples · pairwise comparison · geographic synthesis · safety event
rate normalization · difference-in-differences with synthetic controls

## Source data

Federal Transit Administration National Transit Database (NTD). Public data, updated
annually. Built in R and D3.js.

## How to navigate

Open `index.html` to browse all artifacts, or `Rail_Walkthrough.html` for the
guided tour. Desktop-sized viewport recommended.
